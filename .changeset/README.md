# Changesets

Hello and welcome! This folder has been automatically generated by `@changesets/cli`, a build tool that works
with multi-package repos, or single-package repos to help you version and publish your code. You can
find the full documentation for it [in our repository](https://github.com/changesets/changesets).

## Workflow in this repo

1. After making changes, run `pnpm changeset` to create a changeset describing the bump.
2. Commit the generated `.changeset/*.md` file and open a PR to `main`.
3. When the PR is merged, the `Release` workflow opens/updates a `Release <version>` PR with the
   version bumps and changelogs.
4. Merging that Release PR triggers the `Publish Desktop` workflow, which builds the installers
   and creates a GitHub Release.

Useful commands:

- `pnpm changeset` — create a changeset
- `pnpm changeset:dry` — calculate the next version without applying changes (dry run)
- `pnpm version-packages` — apply the version bumps and update changelogs locally
  (requires `GITHUB_TOKEN` in the environment)
